# Apex Vision — Gtuner IV CV project

This branch is the clean rebuild workspace for a Gtuner IV Computer Vision project.

## Safe project scope
- Configure Gtuner IV's Computer Vision environment.
- Preview and diagnose the PS5 capture-card video feed.
- Display non-targeting capture diagnostics such as frame dimensions and FPS.
- Keep the application visual-only.

This project will not provide enemy-targeting overlays, aim directions, or controller automation for a shooter game.

## Current status
The old application files have been removed from this branch. No working GCV worker has been added yet.

## Environment notes
Gtuner IV's Computer Vision panel runs GCV Python scripts and depends on a compatible Python executable and OpenCV installation. Configure these in Gtuner IV's Computer Vision Preferences before running a GCV script.

The ONNX model is not included in this repository.
